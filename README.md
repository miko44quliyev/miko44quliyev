## 👋 About me

I'm a **Computer Engineering** student at **Baku Engineering University (BMU)** who likes building the part of software users never see: APIs, services and the infrastructure that keeps them running.
Most of my work is **Java + Spring Boot** — from layered REST APIs with JWT security to a microservice platform behind a Spring Cloud Gateway — and I sharpened my full-stack basics in the **Ironhack** bootcamp.
