### 📜 The Syndicate Creed (Engineering Principles)

1. **Zero Trust, Maximum Defense:** Every endpoint is locked down. Strict JWT validation, explicit RBAC gates, and no unvalidated payloads enter the perimeter.
2. **Asynchronous by Design:** Services don't block each other. Event-driven message brokers (RabbitMQ) absorb load spikes so the system never breaks under pressure.
3. **Clean Boundaries or Nothing:** Domain logic stays untainted by framework baggage. Decoupled layers, test-driven validation, and modular architecture ensure code that endures.
